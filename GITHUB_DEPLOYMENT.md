# GitHub и публикация

Репозиторий: https://github.com/x102xx/energy-projects-prototype

Репозиторий и история изменений приватны. Готовый сайт предназначен для просмотра по общей ссылке; это не предоставляет доступ к приватному репозиторию. Содержимое готового frontend доступно браузерам посетителей.

В текущем аккаунте GitHub Pages для приватного репозитория недоступен: GitHub показывает требование обновить тариф. Видимость репозитория не менялась на public. Платный тариф не подключался.

## Подготовка новой версии

```powershell
npm ci
npm run build:pages
```

Папка `docs/` содержит только автономную готовую страницу и `.nojekyll`. Пути не зависят от имени репозитория. Исходники, README, тесты, архивы и исходные задания через эту папку не публикуются.

После появления возможности GitHub Pages: Settings → Pages → Deploy from a branch → main → /docs → Save. Фактическую ссылку и результат публикации нужно проверить после развёртывания. До этого общедоступной ссылки сайта на Pages нет.

Альтернатива: сохранить приватный репозиторий на GitHub и разместить готовую папку `docs/` на отдельном статическом хостинге.
