# GitHub и публикация

Репозиторий: https://github.com/x102xx/energy-projects-prototype

Сайт: https://x102xx.github.io/energy-projects-prototype/

По прямому решению владельца используется публичный репозиторий и бесплатный GitHub Pages. Код, история изменений и готовый сайт общедоступны.

Источник публикации: ветка `main`, папка `/docs`. HTTPS включён. Платный тариф не подключался.

## Подготовка новой версии

```powershell
npm ci
npm run build:pages
```

Папка `docs/` содержит только автономную готовую страницу и `.nojekyll`. Пути не зависят от имени репозитория. Исходники, README, тесты, архивы и исходные задания через эту папку не публикуются.

Настройки: Settings → Pages → Deploy from a branch → main → /docs. После подготовки новой версии нужно закоммитить и отправить изменения, включая `docs/index.html`; GitHub Pages обновит сайт автоматически.

Формы остаются демонстрационными. Публикация не подключает CRM, отправку заявок или внешнюю аналитику.
